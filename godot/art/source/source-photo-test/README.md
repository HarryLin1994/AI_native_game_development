# Source Photo Test Input

Put one test source photo here and name it one of:

```text
current.png
current.jpg
current.jpeg
current.webp
```

`res://scenes/card_art_lab.tscn` automatically loads the first matching file and places it inside
the card art window. If no file is present, the scene renders a placeholder so card layout can
still be tested.

Do not place final generated card art here. Generated/rendered outputs belong in:

```text
godot/art/exports/card-face/
```
